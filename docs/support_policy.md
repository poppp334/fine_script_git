# นโยบายการสนับสนุนหลังส่งมอบ (Support Policy)

## ระยะเวลา
- **14 วัน** นับจากวันที่ตรวจรับ (ลงนามในใบส่งมอบ)

## ครอบคลุม (แก้ให้ฟรี)
- บั๊กของสคริปต์ที่ส่งมอบ (โหลดโมเดลไม่ได้, สคริปต์ error)
- ไฟล์ใน ZIP เสียหาย/ไม่ครบ — ตรวจสอบและส่งซ้ำ
- ช่วยตอบคำถามการใช้งานเบื้องต้น (วิธีรัน Ollama, วิธีโหลดด้วย transformers)
- ปัญหา checksum ไม่ตรงจากความผิดพลาดในการส่งมอบ

## ไม่ครอบคลุม (คิดราคาเป็นงานใหม่)
- เทรนใหม่ / เทรนเพิ่ม (ต่อให้ใช้ข้อมูลเดิม) — เพราะมีค่า GPU และเวลาแยกทุกครั้ง
- แก้ไข/เพิ่ม/ทำความสะอาดข้อมูล แล้วขอเทรนใหม่
- เปลี่ยนโมเดล / ขนาดโมเดล / เทคนิค
- การ deploy ปลายทาง (vLLM บนเซิร์ฟเวอร์ลูกค้า, ตั้งค่า reverse proxy ฯลฯ) — รับเป็น add-on
- ปัญหาที่เกิดจาก cloud ของลูกค้า (เครื่องถูกตัด, disk เต็ม, เครดิตหมด)

## เวลาตอบกลับ
- ใน 14 วัน: ตอบกลับภายใน 24 ชั่วโมง (วันทำการ)
- นอกช่วง: ตอบตามความสะดวก หรือเปิดงานใหม่

## ข้อมูลลูกค้า
- ลบสำเนาไฟล์ข้อมูลลูกค้าออกจากเครื่องผู้ให้บริการภายใน **7 วัน** หลังสิ้นสุด support (หรือเร็วกว่า ตามที่ตกลง)
- ไฟล์โมเดล/ผลลัพธ์ในเครื่องผู้ให้บริการถูกลบเช่นกัน — ไฟล์จริงทั้งหมดอยู่ที่ cloud/เครื่องของลูกค้า

## ยกเลิก / พักงานกลางทาง
- ลูกค้าหยุดกลางทาง: เก็บตามงวดที่ทำงานแล้วเสร็จ (ประเมินตามขั้นตอนจริง)
- ผู้ให้บริการหยุดกลางทางโดยไม่ใช่ความผิดลูกค้า: คืนเงินส่วนที่ยังไม่เริ่มงานทั้งหมด
