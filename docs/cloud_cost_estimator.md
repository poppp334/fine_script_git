# ประมาณการค่า Cloud GPU (แนบ SOW — ลูกค้าอนุมัติก่อนเริ่ม)

> ค่า cloud เป็นของลูกค้าโดยตรง — เอกสารนี้ทำให้ "อนุมัติงบ" วัดได้ ก่อนจ่ายจริง

## 1. สูตรประมาณการ

```
ชั่วโมงเทรน ≈ (จำนวนตัวอย่าง × epochs × วินาทีต่อตัวอย่าง) ÷ 3600
ค่า cloud ≈ ชั่วโมงเทรน × 1.3 (เผื่อ overhead setup/checkpoint/ประเมิน) × เรตบาท/ชม.
```

- **วินาทีต่อตัวอย่าง** จดจาก dry run จริง (รัน 20 steps แล้วหาร) — ห้ามเดา
- บวกเวลา merge/GGUF/eval เพิ่มอีก ~30–60 นาที สำหรับโมเดล ≤7B

## 2. ตาราง GPU (ราคาโดยประมาณ — ต้องเช็คจริงก่อน quote ทุกครั้ง)

| GPU | VRAM | เหมาะกับ (QLoRA) | เรตโดยประมาณ (Vast/RunPod) |
|---|---|---|---|
| T4 16GB | 16GB | 3B–7B (ช้า) | ~$0.20–0.40/ชม. |
| RTX 3090 24GB | 24GB | 7B–13B | ~$0.25–0.50/ชม. |
| RTX 4090 24GB | 24GB | 7B–13B (เร็ว) | ~$0.35–0.70/ชม. |
| A100 40GB | 40GB | 13B–30B | ~$0.80–1.50/ชม. |
| A100 80GB / H100 | 80GB | 70B | ~$1.50–3.00/ชม. |

- **Spot/Interruptible** ถูกกว่า 30–60% แต่ถูกตัดได้ — ระบบเรารองรับ resume จาก checkpoint
- ลูกค้าองค์กรที่ต้องการ invoice/privacy มักใช้ AWS/GCP แพงกว่าแต่ได้เครดิตและเอกสารครบ

## 3. ตัวอย่างการคำนวณ (เคสจริง)

> งาน 7B, ข้อมูล 1,000 ตัวอย่าง, 3 epochs, dry run วัดได้ 2 วินาที/ตัวอย่าง, เลือก RTX 4090 ที่ $0.50/ชม. (≈18 บาท)

1. เวลาเทรน = (1,000 × 3 × 2) ÷ 3600 ≈ **1.7 ชม.**
2. เผื่อ overhead ×1.3 → **2.2 ชม.**
3. ค่า cloud = 2.2 × 18 ≈ **40 บาท** (ถูกมากเมื่อเทียบค่าฝีมือ)

> เคส 70B: 5,000 ตัวอย่าง × 1 epoch × 4 วิ = 5.6 ชม. ×1.3 = 7.2 ชม. × $2.5 ≈ $18 (~650 บาท) — ควรเตือนลูกค้าว่าอย่ารันซ้ำพร่ำเพรื่อ
