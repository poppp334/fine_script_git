# เนื้อหาหน้า Fastwork (พร้อมคัดลอก — ปรับได้ตามจริง)

## ชื่อบริการ (ตัวเลือก)
1. รับทำ Custom LLM Fine-tuning — เทรน AI เฉพาะธุรกิจคุณ (คุณคุม Cloud เอง)
2. เทรน AI ส่วนตัวสำหรับธุรกิจ — ไม่มีค่า GPU แอบแฝง
3. Fine-tune โมเดล AI ภาษาไทยตามสเปค — ข้อมูลอยู่ใน Cloud ของคุณ

## แนะนำตัวเอง (ใช้เต็มหรือตัดสั้น)
คุณกำลังมองหา AI ที่เข้าใจธุรกิจคุณโดยเฉพาะอยู่หรือไม่? แต่กังวลเรื่องค่า GPU ที่สูงและคาดเดาไม่ได้?

ผมให้บริการ **Customize LLM (Fine-tuning)** โดยที่ **คุณเป็นผู้ออกค่า Cloud GPU และผมลงมือเทรนให้ตามสเปค** — คุณไม่ต้องจ่ายบวกลบค่า GPU ที่แฝงในค่าบริการ เลือก cloud ถูกที่สุดได้เอง และข้อมูลอยู่กับคุณ 100%

**เหมาะกับ:** องค์กรที่ต้องการโมเดลเฉพาะทาง (กฎหมาย/การแพทย์/บริการลูกค้า) · นักพัฒนาที่สร้างโมเดลเฉพาะงาน · งานที่ข้อมูลต้องอยู่บน cloud ตัวเอง

## ขั้นตอนทำงาน (7 ขั้น)
1. **Consult & Spec** — คุยความต้องการ อนุมัติสเปค (โมเดล/เทคนิค/epochs)
2. **Data Preparation** — รับข้อมูล + ตรวจคุณภาพ (มีคู่มือรูปแบบข้อมูลให้)
3. **Script Development (Lab)** — เขียนและทดสอบสคริปต์บนเครื่องผม
4. **Cloud Setup (Client)** — คุณเปิดเครื่อง cloud และให้สิทธิ์ SSH
5. **Training (Factory)** — ผมรันเทรนบน cloud ของคุณ พร้อม monitor
6. **Evaluation** — รายงานผลก่อน/หลัง + ปรับ hyperparameter 1 ครั้งฟรี
7. **Delivery** — ส่ง adapter/merged/GGUF + สคริปต์ + คู่มือ + checksum

## จุดเด่น (เขียนเป็น bullet บนหน้าเพจ)
- ✅ Zero Hidden Cost — จ่ายค่าฝีมือล้วน ไม่บวกค่า GPU
- ✅ คุณเลือก Cloud เอง — RunPod / Vast.ai / AWS / GCP / GPU VPS ไทย
- ✅ ข้อมูลไม่ออกจาก Cloud คุณ — เทรนในบัญชีคุณ ลบไฟล์ที่ผมหลังส่งมอบ (NDA ได้)
- ✅ ได้ไฟล์พร้อมใช้ — Adapter + Merged + GGUF (Ollama) + รายงานผล
- ✅ ประมาณการค่า cloud ให้อนุมัติก่อนเริ่มทุกครั้ง — ไม่มีบิลผี

## FAQ สั้น (ใส่ท้ายเพจ)
- **ข้อมูลปลอดภัยไหม?** อยู่ในบัญชี cloud ของคุณเท่านั้น + NDA ได้
- **ต้องมีข้อมูลกี่คู่?** เริ่ม 300–500 คู่คุณภาพดีก็เห็นผล (มาครึ่งทางได้ด้วย)
- **ใช้เวลาเท่าไหร่?** ตามแพ็ก 2–20 วัน (นับจากข้อมูล+cloud พร้อม)
- **ค่า cloud ประมาณเท่าไหร่?** 7B ≈ 40–200 บาทต่อรอบเทรน ขึ้นกับ cloud/ข้อมูล — ผมคำนวณให้ก่อนเริ่ม
