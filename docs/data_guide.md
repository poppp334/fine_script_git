# คู่มือเตรียมข้อมูลสำหรับ Fine-tuning (ส่งให้ลูกค้าอ่านก่อนส่งข้อมูล)

> หลักสำคัญ: **500 ตัวอย่างที่ดี > 5,000 ตัวอย่างที่ปนขยะ**
> โมเดลจะเลียนแบบสิ่งที่อยู่ในข้อมูล — ถ้าข้อมูลสวย ผลลัพธ์สวย

## 1. รูปแบบที่รับได้

### 1.1 JSONL แบบ ChatML (แนะนำที่สุด)

ไฟล์ `.jsonl` หนึ่งบรรทัด = หนึ่งบทสนทนา:

```json
{"messages": [{"role": "user", "content": "ร้านเปิดกี่โมง"}, {"role": "assistant", "content": "ร้านเปิด 9:00–21:00 ครับ"}]}
```

- ใส่ `system` prompt นำหน้าได้ถ้าต้องการกำหนดบุคลิก (ไม่ใส่ก็ได้)
- หลายรอบสนทนาได้: สลับ user/assistant ต่อกันใน `messages`
- ไฟล์ต้องเป็น UTF-8 (ภาษาไทยไม่ต้องแปลงเป็น Unicode escape)

### 1.2 CSV / Excel

ต้องมีคอลัมน์ชื่อ `question` และ `answer` (สะกดตรงเป๊ะ):

| question | answer |
|---|---|
| ร้านเปิดกี่โมง | ร้านเปิด 9:00–21:00 ครับ |
| ค่าส่งเท่าไหร่ | เริ่มต้น 35 บาทครับ |

- ไฟล์ `.csv` ต้องเป็น UTF-8
- ช่องว่าง = แถวนั้นถูกข้าม (ระบบรายงานให้ทราบ)

### 1.3 Plain text
สำหรับงาน Continued Pretraining (ให้โมเดล "อ่าน" เอกสารจำนวนมาก) — สอบถามก่อนส่ง เพราะขั้นตอนต่างจากงานแชท

## 2. กติกาคุณภาพข้อมูล (เช็คก่อนส่งทุกครั้ง)

**ควรมี**
- คำตอบสไตล์เดียวกันทั้งไฟล์ (สุภาพ/ทางการ/กันเอง — เลือกอย่างเดียว)
- คำถามหลากหลายวิธีพูดในเรื่องเดียวกัน (เช่น "เปิดกี่โมง" / "กี่โมงถึงปิด" / "ไป 3 ทุ่มยังทันไหม")
- คำตอบสั้น-กระชับตามที่อยากให้โมเดลตอบจริง (ความยาวคำตอบ = สิ่งที่โมเดลจะเลียนแบบ)
- ข้อมูล "เรื่องเดียวกันอยู่ด้วยกัน" — ถ้ามีหลายเรื่อง ให้แยกหัวข้อชัดเจน

**ไม่ควรมี**
- คำตอบว่าง / "ไม่ทราบ" / คำตอบซ้ำกันพร่ำเพรื่อ
- ข้อมูลส่วนบุคคล (ชื่อ-นามสกุลลูกค้า, เบอร์โทร, เลขบัตร, ที่อยู่) — ถ้าจำเป็นต้องใช้ ให้ทำ anonymize ก่อน
- ข้อความที่คัดลอกจากที่อื่นทั้งย่อหน้าโดยไม่มีสิทธิ์
- อีโมจิ/สัญลักษณ์แปลกๆ ปนเยอะ (โมเดลจะเลียนแบบ)

## 3. ปริมาณที่เหมาะกับแต่ละแพ็ก

| แพ็ก | จำนวนตัวอย่างแนะนำ | หมายเหตุ |
|---|---|---|
| Micro | 50–1,000 | งานทดลอง/ตอบคำถามเฉพาะเรื่อง |
| Starter | 500–5,000 | แชทบอท 1 โดเมน |
| Standard | 1,000–20,000 | หลายรูปแบบคำถาม ต้องการคุณภาพสูง |
| Pro | 5,000–20,000+ | หลาย adapter / งานซับซ้อน |

**คุณภาพ > ปริมาณเสมอ:** เริ่มจาก 300–500 คู่ที่สวย แล้วเติมทีหลังได้

## 4. ก่อนกดส่ง — เช็คลิสต์ 5 ข้อ

- [ ] ไฟล์ UTF-8, เปิดอ่านด้วย editor แล้วภาษาไทยไม่แตก
- [ ] ไม่มีแถวว่าง/คำตอบว่าง
- [ ] คำตอบทุกแถวสไตล์เดียวกัน
- [ ] ไม่มีข้อมูลส่วนบุคคล (หรือ anonymize แล้ว)
- [ ] แจ้งหัวข้อ/บริบทเพิ่มเติมมาด้วย (เช่น ต้องการให้แทนตัวเองว่าอะไร)

> เมื่อได้รับข้อมูลแล้ว ผมจะรันตัวตรวจคุณภาพ (`validate_data.py`) และส่งรายงานกลับให้ยืนยันก่อนเริ่มเทรนทุกครั้ง
