# แบบสอบถามก่อนประเมินราคา (ยิงก่อน quote ทุกครั้ง)

> ใช้ประกอบบทสนทนากับลูกค้า — 10 ข้อนี้ทำให้ประเมินราคา/เวลา/cloud ได้แม่นภายในครั้งเดียว

## 1. เป้าหมายการใช้งาน
อยากให้ AI ทำงานอะไร? ตัวอย่างคำตอบที่ใช้ได้: แชทบอทตอบลูกค้า / ผู้ช่วยเขียนอีเมล / สรุปเอกสาร / แปลศัพท์เฉพาะทาง
→ *ใช้กำหนด: งานแชท (SFT) vs งานสไตล์ (DPO) vs งานอ่านเอกสาร (CPT)*

## 2. ตัวอย่างคำถาม-คำตอบจริง
ขอตัวอย่าง 5–10 คู่ที่ "คำตอบแบบที่ต้องการ" — อย่างน้อย 1 คู่
→ *ใช้ดูคุณภาพข้อมูล + ประเมินว่างานเข้าเกณฑ์ไหม*

## 3. ข้อมูลที่มีอยู่
มี dataset แล้วหรือยัง? ประมาณกี่ตัวอย่าง? รูปแบบไหน (JSONL / Excel / CSV / แชทล็อก)?
→ *ใช้เลือกแพ็ก + ประเมินเวลาทำ data*

## 4. ภาษาและสไตล์
ภาษาไทยล้วน / ไทย-อังกฤษผสม? คำตอบทางการหรือกันเอง? แทนตัวเองว่าอะไร?
→ *ใช้ตั้ง system prompt + ตรวจข้อมูล*

## 5. ขนาดโมเดล
มีโมเดลในใจไหม (0.5B–3B / 7B / 13B+)? ถ้าไม่แน่ใจเริ่ม 0.5B–7B ได้
→ *ใช้เลือก cloud GPU + ประมาณค่าใช้จ่าย*

## 6. ปลายทางที่เอาไปใช้
จะรันที่ไหน? เครื่องตัวเอง (Ollama/LM Studio) / เซิร์ฟเวอร์บริษัท (vLLM) / แอป?
→ *ใช้กำหนดรูปแบบไฟล์ส่งมอบ (GGUF vs Merged vs Adapter)*

## 7. ความเร็วที่ต้องการ
ต้องตอบเร็วแค่ไหน? กี่คำขอพร้อมกัน? (มีผลกับขนาดโมเดล + GPU ที่ต้องใช้)
→ *ใช้เตือนถ้าความคาดหวังไม่ตรงกับขนาดโมเดลที่เลือก*

## 8. Cloud และงบประมาณ
สะดวกใช้ cloud เจ้าไหน (RunPod / Vast.ai / AWS / GCP)? งบ cloud ต่อชั่วโมงเท่าไหร่?
→ *ใช้แนะนำ GPU ที่คุ้มที่สุด + ประมาณการใน SOW*

## 9. ไทม์ไลน์
อยากได้ภายในกี่วัน? มีเดดไลน์ตายตัวไหม?
→ *ใช้ยืนยันความเป็นไปได้ (เทรนจริง 1–3 วัน + คิวงาน)*

## 10. เกณฑ์ความสำเร็จ + ผู้ดูแลต่อ
อะไรทำให้ลูกค้าบอกว่า "งานสำเร็จ"? (เช่น ตอบถูก 8/10 ข้อในชุดทดสอบของลูกค้า) — และหลังส่งมอบใครดูแลต่อ?
→ *ใช้เขียน Acceptance criteria ใน SOW ให้วัดได้*
